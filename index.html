About Me

Building practical cybersecurity skills

I'm a cybersecurity enthusiast focused on developing practical skills in Security Operations, threat detection, network security, and incident investigation.

My learning approach is hands-on. Instead of only studying security concepts theoretically, I build labs, generate security telemetry, investigate events, analyze network traffic, and document the findings.

My projects cover areas such as Wireshark packet analysis, Splunk investigations, Sysmon threat hunting, phishing analysis, ransomware investigations, cloud security, and network security.

I use these projects to develop the practical investigation mindset required in a SOC environment: understanding what happened, finding the evidence, determining whether activity is malicious, and documenting the investigation clearly.
